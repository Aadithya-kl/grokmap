# Install the tool

Grok-map works out who wrote each line from your **git history**, on your computer.

**Install for me** tries, in order:

1. `uv tool install grokmap`, if you have [uv](https://docs.astral.sh/uv/)
2. `pip install --user grokmap` with your Python (3.11 or newer)

Prefer to do it yourself? Run one of these in a terminal:

```
pip install grokmap
uv tool install grokmap
```

Grok-map makes no network calls of its own and needs no account or API key.
