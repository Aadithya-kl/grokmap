# Pick a repository

Click the **Grok-map** icon in the activity bar, then **Choose a repository**.

The dashboard shows:

- how much of the **AI-written** code anyone on your team understands
- the files that **need attention**: click one to open it, or **Quiz** to test yourself on it
- **who** understands what, and which agents wrote the code
- how much of each week's new code came from AI

Open any file in the repository and it also gets coloured in the gutter:
red where nobody has checked it, green where someone understands it.
