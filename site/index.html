Your tests pass. Could anyone debug it at 2am?

Coding agents now write a large share of the code teams ship. It gets reviewed quickly, merged, and forgotten. When it breaks, nobody has a mental model of how it works. That gap doesn't show up in linters, coverage or review dashboards. grokmap makes it visible.

1 · ATTRIBUTE

Every line, traced to its author

git blame maps each line to the commit that wrote it. Commits carrying an agent's marker, such as a Co-Authored-By: Claude trailer, count as AI-written.

2 · QUIZ

Your agent checks you understand it

The grokmap skill gives you a short quiz on exactly the lines you haven't seen, grades you honestly, and records the result. Edited lines need understanding again.

3 · MAP

See where the risk is

A zoomable heatmap, a README badge, a weekly trend by agent, and a pull request comment that says how much of the change anyone understands.

Questions

What is comprehension debt?

The gap between how much code exists in a system and how much of it any person actually understands. A longer explanation, with how to measure it.

Is there an MCP server?

Yes: uvx grokmap-mcp, listed in the official MCP Registry as io.github.Aadithya-kl/grokmap. It gives Claude Code, Cursor, Codex, VS Code and other clients tools such as comprehension_risk, which says how well the team understands a file before the agent changes it, and quiz_brief and record_understanding for quizzes. It runs locally with no API keys.

How do I find out how much of my code was written by AI?

Run grokmap status. It counts lines from commits that carry an AI agent's marker. grokmap trend shows how that changed month by month.

Is this surveillance?

No. It measures code, not people. Nobody is quizzed unless they ask, and the ledger only holds what people choose to record.

What if AI code was pasted from a chat window?

grokmap can't see it and counts it as human-written. Detection is deliberately conservative: it only uses evidence in commit metadata.

Does it cost anything?

No. grokmap is MIT-licensed open source.
